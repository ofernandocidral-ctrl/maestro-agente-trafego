# Contexto da operação | Modelo

> O Maestro pode criar `CONTEXTO.md` a partir deste arquivo durante o onboarding. Preencha apenas o que souber. Este arquivo de exemplo é público; mantenha o arquivo real fora do GitHub.

## Essencial

- Apelido da operação:
- Tipo: marca própria / operação de cliente (uma pasta isolada por cliente)
- Produtos ou categorias prioritárias:
- Plataformas de anúncios:
- Objetivo e horizonte de análise:
- Investimento aproximado e moeda:
- Ticket médio: valor, fonte ou `desconhecido`
- Margem de contribuição antes do marketing: valor, fonte ou `desconhecida`
- Fonte de vendas (loja, ERP, checkout):
- Tom preferido: conversacional / neutro / técnico / outro

## Preencha quando a análise precisar

- Fuso da conta e da loja:
- Janela/modelo de atribuição:
- Receita usada: bruta / líquida / após devoluções / desconhecida
- Meta de CPA, ROAS, MER ou contribuição:
- Categorias com margens diferentes:
- Histórico, sazonalidade, promoções ou mudanças recentes:
- Limites e preferências para recomendações:

## Estado de confiabilidade

- Dados de anúncios: não enviados / recebidos / validados / divergentes
- Dados da loja: não enviados / recebidos / validados / divergentes
- Margem: desconhecida / informada / documentada
- Última atualização:

**Nunca inclua:** senhas, tokens, chaves, cookies, dados pessoais de compradores, pedidos individualizados ou informações confidenciais de clientes.
