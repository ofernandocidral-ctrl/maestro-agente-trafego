# Antes de publicar no GitHub

Esta pasta está preparada para revisão e publicação manual. Confira estes itens:

- [ ] Decidir se o repositório será público ou privado.
- [ ] Definir a licença (uso, cópia, modificações e redistribuição comercial).
- [ ] Revisar o nome do produto, autoria e links de contato que deseja mostrar.
- [ ] Confirmar que `exemplos/campanhas-ficticias.csv` é a única planilha incluída.
- [ ] Confirmar que não há credenciais, contexto real, dados de clientes ou arquivos internos.
- [ ] Abrir o README no GitHub e conferir a renderização.
- [ ] Fazer a conferência inicial numa ferramenta que carregue as instruções do projeto.

Não adicione `CONTEXTO.md`, `JORNADA.md`, dados de operação ou relatórios reais ao repositório. O `.gitignore` é apenas uma proteção complementar: confira os arquivos staged antes de publicar.
